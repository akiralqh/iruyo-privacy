# iruyo アプリ プライバシーポリシー

**最終更新日:** 2026年1月16日

### 1. はじめに

「iruyo」アプリ（以下、「本アプリ」といいます）は、お客様のプライバシーを尊重します。本プライバシーポリシーは、本アプリが収集する情報、その使用方法、およびお客様の権利について説明するものです。

### 2. 収集する情報

「iruyo」のコアサービスを提供するため、以下の情報を収集します。

*   **匿名デバイス識別子**: アプリの初回起動時に、ランダムな匿名デバイス識別子を生成します。この識別子を使用してお客様のアカウントとデータを管理し、お客様が登録時に個人識別情報（氏名、電話番号、メールアドレスなど）を提供する必要がないようにします。

*   **緊急連絡先情報および手紙の内容**: 本アプリでは、お客様が指定した受信者のメールアドレスと送信したいテキスト内容を含む「手紙」を1つ以上作成できます。これらの情報は、本アプリのコア機能を実装するために必要です。

### 3. 情報の使用方法

緊急連絡先情報および手紙の内容は、お客様が設定した時間内に「いるよ」ボタンをタップしてチェックインできなかった場合に、システムが自動的にお客様の指定した受信者のメールアドレスに手紙の内容を送信するという、ただ1つの目的でのみ使用されます。お客様の匿名デバイス識別子は、お客様のデータと関連付け、検証するためにのみ使用されます。

### 4. データの保存とセキュリティ

お客様がアプリ内で作成したすべてのデータ（匿名デバイス識別子、受信者のメールアドレス、手紙の内容を含む）は、MongoDBデータベースに安全に保存されます。
本アプリは、お客様のデータを不正なアクセス、使用、開示から保護するために、商業的に合理的なセキュリティ対策を講じることをお約束します。

### 5. データ共有

本アプリは、お客様のプライバシーを非常に重視しています。お客様の個人データを販売、取引、またはその他の方法で第三者に譲渡することはありません。
※お客様の手紙を送信するために、手紙の内容と受信者のメールアドレスを当社のメール送信サービスプロバイダーに提供する必要がある場合です。これ以外に、お客様のデータが第三者と共有されることはありません。

### 6. お客様の権利とデータ管理

お客様はご自身のデータを完全に管理する権利を有します。本アプリを通じていつでも以下の操作が可能です。

*   新しい手紙の作成。
*   作成した手紙の内容および受信者情報の表示と編集。
*   保持したくない手紙の削除。手紙を削除すると、それに関連するすべてのデータが当社のサーバーから永久に削除されます。
