 # プライバシーポリシー
 
 **最終更新日:** 2026年2月5日
 
 本プライバシーポリシーは、「iruyo」（以下、「本アプリ」）が収集する情報、その利用方法、およびユーザーの権利について説明するものです。
 
 ## 1. 収集する情報
 
 本アプリは、以下の機能を提供するために、それぞれ必要な情報を収集します。
 
 *   **見守り機能（iruyo）:**
     *   もしもの時に手紙を送信するための、宛先の氏名およびメールアドレス。
     *   ユーザーが作成した手紙の内容（テキスト、画像、動画ファイル等）。
     *   安否確認のための最終ログイン日時および設定された確認間隔。
 
 *   **AIアシスタント機能（Hanaso）:**
     *   ユーザーが入力したテキストメッセージ。
     *   ユーザーがアップロードした画像データ。
     *   ユーザーの音声入力からデバイス上で変換されたテキストデータ。
     *   AIが高度な機能（Web検索、リマインダー設定等）を実行するために必要な関連データ（例：検索語、場所、イベント詳細など）。
 
 ## 2. 情報の利用目的
 
 当社は、収集した情報を以下の目的で利用します。
 
 *   **見守り機能（iruyo）:** ユーザーが設定した期間内に安否確認が取れなかった場合に、指定された連絡先へ自動的に手紙を送信するため。
 *   **AIアシスタント機能（Hanaso）:** ユーザーの質問や指示に対する応答生成、画像内容の分析、Web検索、リマインダー設定等のAIアシスタント機能を提供するため。
 *   **共通:** サービスの改善、カスタマーサポート、および利用規約の遵守のため。
 
 ## 3. 情報の第三者提供
 
 当社は、法令に基づく場合を除き、ユーザーの同意なしに個人情報を第三者に提供することはありません。ただし、以下の例外があります。
 
 ### AI機能（Hanaso）における第三者提供
 
 本アプリのAIアシスタント機能「Hanaso」の提供にあたり、当社は収集した情報を安全な方法で当社のサーバーを経由し、第三者のAIサービス提供事業者に送信します。当社が現在利用している主要なAIサービス提供事業者は以下の通りです。
 
 *   **事業者名:** Google LLC
 *   **利用するサービス:** Googleが提供するGemini等のAIモデル
 
 将来、最高のサービスを提供するために、他のトップレベルのAIサービス提供事業者（例：OpenAI等）を追加または変更する可能性があります。その際は、本プライバシーポリシーを速やかに更新し、告知いたします。
 
 ## 4. データ保護
 
 当社は、収集した情報の紛失、盗用、悪用、不正アクセス、開示、改ざん、および破壊を防ぐため、技術的および管理的なセキュリティ対策を講じています。特に、AI機能で送信されるデータは、ユーザーの個別のリクエスト処理にのみ使用され、業界標準のセキュリティ対策によって
 護されます。ユーザーの個人データが、汎用的なAIモデルのトレーニング等、本来の目的以外に利用されることはありません。
